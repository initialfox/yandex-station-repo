[QUOTE]Нужен [B]root[/B] (SSH или ADB).

Две версии ОС на колонках:
[LIST]
[*] [B]Android[/B] — /data/local/bin, /data/local/opt
[*] [B]buildroot[/B] — /usr/local/bin или /opt (часто rootfs [B]read-only[/B] → сначала remount rw)
[/LIST]
[/QUOTE]

Один бинарь [B]apkg[/B]. Пакеты качает сам с GitHub (ветка [B]pkg[/B]).

[SPOILER=Установка через ADB (с компа)]
[CODE]
git clone https://github.com/initialfox/yandex-station-repo.git
cd yandex-station-repo
./scripts/install-adb.sh
# конкретное устройство:
./scripts/install-adb.sh -s IP:5555
[/CODE]
Скрипт качает apkg, делает [B]adb push[/B], сам определяет Android / buildroot.
На buildroot пробует [B]mount -o remount,rw /[/B].
[/SPOILER]

[SPOILER=Установка по SSH / на станции]
Если DNS живой:

[CODE]
curl -kfsSL https://raw.githubusercontent.com/initialfox/yandex-station-repo/main/install.sh | sh
[/CODE]

Часто на колонке DNS мёртвый ([B]Could not resolve host[/B], resolv → ::1:53). Тогда:

[CODE]
curl -kfsSL --resolve raw.githubusercontent.com:443:185.199.108.133 \
  https://raw.githubusercontent.com/initialfox/yandex-station-repo/main/install.sh | sh
[/CODE]

На [B]buildroot[/B], если Read-only file system:

[CODE]
mount -o remount,rw /
[/CODE]

Флаг [B]-k[/B] у curl обязателен (нет CA на станции).
[/SPOILER]

[SPOILER=Команды]
[CODE]
export PATH=/data/local/bin:/usr/local/bin:$PATH   # что актуально

apkg version
apkg paths                 # flavor android | buildroot
apkg update
apkg list
apkg search vpn
apkg install nano curl btop
apkg install zsh fastfetch neofetch
apkg install openvpn
apkg remove nano
apkg upgrade
[/CODE]

Musl-пакеты запускай по имени из PATH (обёртка), не голый файл из opt/.../bin/.
[/SPOILER]

[SPOILER=Важно / частые грабли]
[LIST]
[*] [B]buildroot + read-only[/B] — без [CODE]mount -o remount,rw /[/CODE] ничего не поставится
[*] [B]DNS[/B] — если curl не резолвит GitHub, используй --resolve (см. выше) или ставь через ADB push
[*] Обновляй apkg: [CODE]apkg version[/CODE] (актуально 1.0.7+)
[*] После обновления индекса: [CODE]apkg update[/CODE]
[*] neofetch — bash-скрипт, нужен [B]bash[/B] в PATH (или ставь fastfetch — нативный бинарь)
[/LIST]
[/SPOILER]
