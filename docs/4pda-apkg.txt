[SIZE=2]Android + buildroot · aarch64 · [URL=https://github.com/initialfox/yandex-station-repo]yandex-station-repo[/URL][/SIZE]

[QUOTE]
Нужен [B]root[/B] (SSH или ADB).

Две версии ОС:
[LIST]
[*] [B]Android[/B] — ставит в [CODE]/data/local/bin[/CODE], [CODE]/data/local/opt[/CODE]
[*] [B]buildroot[/B] — [CODE]/usr/local/bin[/CODE] / [CODE]/opt[/CODE] (часто rootfs [B]read-only[/B] → сначала [CODE]mount -o remount,rw /[/CODE])
[/LIST]
[/QUOTE]

Один бинарь [B]apkg[/B]. Пакеты качает сам с GitHub (ветка [B]pkg[/B]), вручную ничего тащить не нужно.

[SPOILER="1. Установка — ADB с компа (рекомендуется)"]
[CODE]
git clone https://github.com/initialfox/yandex-station-repo.git
cd yandex-station-repo
./scripts/install-adb.sh
# несколько устройств / Wi‑Fi ADB:
./scripts/install-adb.sh -s IP:5555
[/CODE]

Скрипт:
[LIST]
[*] качает свежий apkg
[*] делает [B]adb push[/B]
[*] сам определяет Android / buildroot
[*] на buildroot пробует remount rw
[*] запускает [CODE]apkg update[/CODE]
[/LIST]
[/SPOILER]

[SPOILER="2. Установка — SSH с компа"]
[CODE]
./scripts/install-ssh.sh root@IP
./scripts/install-ssh.sh -p 2222 root@host
[/CODE]
На станции выполняется [CODE]install.sh[/CODE] (Android / buildroot + remount).
[/SPOILER]

[SPOILER="3. Установка — одной строкой на станции"]
Если DNS живой:

[CODE]
curl -kfsSL https://raw.githubusercontent.com/initialfox/yandex-station-repo/main/install.sh | sh
[/CODE]

Часто DNS битый ([B]Could not resolve host[/B], в resolv.conf → [CODE]::1:53[/CODE]). Тогда:

[CODE]
curl -kfsSL --resolve raw.githubusercontent.com:443:185.199.108.133 \
  https://raw.githubusercontent.com/initialfox/yandex-station-repo/main/install.sh | sh
[/CODE]

[B]buildroot[/B] + read-only:

[CODE]
mount -o remount,rw /
curl -kfsSL --resolve raw.githubusercontent.com:443:185.199.108.133 \
  https://raw.githubusercontent.com/initialfox/yandex-station-repo/main/install.sh | sh
[/CODE]

[B]-k[/B] у curl обязателен — на колонке часто нет CA.
[/SPOILER]

[SPOILER="Команды"]
[CODE]
# PATH (что актуально для твоей ОС):
export PATH=/data/local/bin:$PATH          # Android
export PATH=/usr/local/bin:/opt/bin:$PATH  # buildroot

apkg version
apkg paths          # flavor: android | buildroot
apkg update
apkg list
apkg search vpn
apkg install nano curl btop
apkg install zsh fastfetch
apkg install openvpn
apkg remove nano
apkg upgrade
[/CODE]

Musl-пакеты запускай [B]по имени из PATH[/B] (обёртка), не голый ELF из [CODE]opt/.../bin/[/CODE].
[/SPOILER]

[SPOILER="Частые грабли"]
[LIST]
[*] [B]buildroot read-only[/B] → [CODE]mount -o remount,rw /[/CODE]
[*] [B]DNS[/B] → [CODE]--resolve[/CODE] или ставь через ADB push
[*] Обновляй менеджер: [CODE]apkg version[/CODE] (нужен [B]1.0.7+[/B])
[*] После правок в репе на станции: [CODE]apkg update[/CODE]
[*] Если команда «not found» у musl — запускаешь голый ELF; нужен путь из PATH
[/LIST]
[/SPOILER]
